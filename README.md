# PariTok AI Agent Optimization

An independent product, data, and engineering extension plan for [PariTok-4B-v1](https://github.com/Paritok-official/paritok-4b-v1), an open-source context-compression gateway for coding agents.

This repository does **not** claim authorship of the upstream PariTok project. It turns the project into a reproducible portfolio case study focused on:

- safe and measurable context optimization;
- cost-per-success analytics;
- AI product and product-operations decisions;
- honest US and China résumé positioning;
- a reusable Codex Skill for evaluating other AI-agent projects.

## Repository contents

- [`docs/paritok-improvement-roadmap.md`](docs/paritok-improvement-roadmap.md): prioritized second-development plan.
- [`docs/evaluation-plan.md`](docs/evaluation-plan.md): paired experiment and KPI design.
- [`skills/ai-agent-project-strategist/`](skills/ai-agent-project-strategist/): reusable Codex Skill.

## Recommended portfolio build

Start with the evaluation lab and reliability guardrails before modifying the compression model. This path creates credible evidence for data analyst, AI product manager, and AI product operations roles while addressing the project's most important adoption risk: savings that cannot be trusted.
